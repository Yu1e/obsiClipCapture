# Obsiclipcapture

> ⚠️ **Написано полностью Клодом.** Каждую строку кода, как и оба файла README, создал Клод — ИИ-ассистент Anthropic — в переписке в чате. Владелец репозитория поставил требования и проверил результат в работе; построчной проверки кода человеком не было. Используйте на свой риск.

Утилита в трее, которая пишет в хранилище Obsidian при закрытом Obsidian. Две задачи, один процесс, одна иконка:

| Задача | Хоткей по умолчанию | Что происходит |
|---|---|---|
| **Клип** | `Ctrl+Alt+F8` | Выделенное уходит в новую заметку, в свойство `source` попадает адрес страницы или заголовок окна |
| **Быстрая заметка** | правый `Alt` | Поднимается окошко ввода, текст дописывается в накопительный markdown-файл |

Заметки ложатся на диск обычными markdown-файлами. Obsidian подхватит их при следующем сканировании, так что открытым он быть не должен — и даже установленным на той машине, где идёт захват.

🇬🇧 [English version](README.md)

## Требования

- Windows 10 или 11
- PowerShell 5.1 и .NET Framework 4.x — оба идут в комплекте с Windows
- Obsidian по желанию. Он нужен только кнопке «Перейти в заметку» и вызову Templater
- Плагин [Advanced URI](https://github.com/Vinzent03/obsidian-advanced-uri), если на каждый клип должна срабатывать команда Templater

## Установка

1. Положить `Obsiclipcapture.ps1` и `start.vbs` в одну папку.
2. Запустить `start.vbs` (или `Obsiclipcapture.bat`). Иконка в трее появится секунды через три — задержка встроена намеренно, чтобы при автозапуске скрипт не опережал готовность системы.
3. При первом запуске само откроется окно настроек клиппера. Указать полный путь к хранилищу, сохранить.
4. Правый клик по иконке → **Настройки заметок** — настроить вторую половину.

Чтобы обойтись без первичной настройки, положите готовый `obsiclipcapture.cfg` рядом со скриптом до первого запуска.

### Автозапуск

`Win+R` → `shell:startup` → Enter, в открывшуюся папку положить ярлык на `start.vbs`.

## Быстрые заметки

| Действие | Клавиши |
|---|---|
| Открыть окошко | правый `Alt`, левый клик по иконке трея или меню → «Новая заметка» |
| Сохранить и закрыть | `Ctrl+Enter` |
| Закрыть без сохранения | `Escape` |

Текст, закрытый через `Escape`, остаётся черновиком и подставляется при следующем вызове — до перезапуска утилиты. Размер и положение окна запоминаются сразу при закрытии.

Файл за день выглядит так:

```markdown
---
tags: ежедневка
создано: 2026 09 18
---

🕐 Первая мысль

🕝 Вторая мысль
```

Эмодзи-часы идут с шагом полчаса — 🕐 🕜 🕑 🕝 и далее по кругу. Ощущение времени записи сохраняется, а точная минута в заметку не попадает.

## Настройки

Всё лежит в `obsiclipcapture.cfg` рядом со скриптом, в виде `ключ=значение`. Правят его два окна: **Настройки клиппера** и **Настройки заметок**. Каждое пишет только свою половину, чужая переносится в файл без изменений.

### Клиппер

| Поле | Что делает |
|---|---|
| Путь к хранилищу | Полный путь к хранилищу Obsidian |
| Папка для заметок | Куда складывать клипы, путь от корня хранилища |
| Папка вложений | Куда сохранять картинки из клипов, путь от корня хранилища |
| Свойство даты, формат даты | Имя свойства и формат даты .NET в каждом клипе |
| Свойства заметки | Дополнительные ключи фронтматтера для каждого клипа |
| Шаблон Templater | Идентификатор команды, которая вызывается через Advanced URI после записи клипа |
| Горячая клавиша | `Ctrl` / `Alt` / `Shift` плюс F-клавиша |

### Быстрые заметки

| Поле | Что делает |
|---|---|
| Папка-накопитель | Путь от корня хранилища либо полный путь с буквой диска — в том числе за пределами хранилища |
| Шаблон имени файла | `{date:ФОРМАТ}` с любым форматом даты .NET. Подпапки допустимы: `{date:yyyy}\Неделя {date:ww}.md` |
| Шаблон записи | `{clock}` — эмодзи-часы, `{text}` — текст заметки |
| Разделитель записей | `\n\n` — пустая строка между записями, `\n` — подряд |
| Свойства заметки | Фронтматтер при создании файла. Значения принимают `{date:ФОРМАТ}` |
| Одиночный модификатор | Правый `Alt` и подобные, ловятся опросом клавиатуры |
| Модификаторы + F-клавиша | Работает, когда одиночный модификатор выставлен в «не использовать» |
| Тема | Светлая или тёмная |
| Миганий при появлении | Сколько раз мигнёт заголовок. `0` — без мигания |
| Шрифт, размер | Вид поля ввода |

## Как устроено

Один скрипт PowerShell компилирует набор классов C# через `Add-Type` и запускает скрытую форму-носитель, которой принадлежат оба хоткея и иконка в трее.

Хоткей клиппера идёт через `RegisterHotKey`. Хоткей заметки идёт одним из двух путей: `RegisterHotKey` для сочетания с клавишей либо опрос `GetAsyncKeyState` каждые 40 мс, если выбран одиночный модификатор вроде правого `Alt`. Windows отказывается регистрировать одинокий модификатор как хоткей, так что опрос здесь — единственная дорога.

Клип читает выделение, посылая `Ctrl+C` через `keybd_event`, предварительно дождавшись, пока физические модификаторы хоткея будут отпущены. Если их удерживать, посланное нажатие превратится в `Ctrl+Alt+C` и буфер останется пустым. Прежнее содержимое буфера возвращается после записи.

## Устранение неполадок

Начинать с `obsiclipcapture.log` рядом со скриптом. Туда пишется каждый запуск и каждая ошибка компиляции.

**Иконка не появилась.** Запустить `Obsiclipcapture.ps1` напрямую из окна PowerShell — текст ошибки будет на экране.

**Появляется или остаётся окно консоли.** Менять надо лончер: запуск через `start.vbs` вместо вызова `powershell.exe` из батника не даёт консоли создаться вовсе.

**Один из хоткеев молчит.** Навести курсор на иконку в трее — подсказка показывает оба текущих сочетания. Баллон при запуске о неудачной регистрации означает, что сочетание занято другой программой.

**Кириллица в меню трея — кракозябры.** `Obsiclipcapture.ps1` пересохранён без BOM, и PowerShell 5.1 читает его как ANSI. Сохранить как UTF-8 с BOM.

**Заметки уходят не туда.** Относительная папка-накопитель считается от пути к хранилищу, так что при пустом пути заметки окажутся в неожиданном месте.

## Файлы репозитория

| Файл | Роль |
|---|---|
| `Obsiclipcapture.ps1` | Сама утилита. Сохранять в UTF-8 **с BOM** |
| `start.vbs` | Лончер — запускает PowerShell без окна консоли |
| `Obsiclipcapture.bat` | Батник-обёртка над `start.vbs`, по желанию |
| `obsiclipcapture.cfg` | Настройки. Создаётся при первом запуске |
| `obsiclipcapture.log` | Лог запусков и ошибок |

# Obsiclipcapture — инструкция

Клиппер и быстрые заметки в одном процессе: одна иконка в трее, один файл настроек, два независимых хоткея.

| Что делает | Как вызывается |
|---|---|
| Клип: выделенное в новую заметку с `source` | `Ctrl+Alt+F8` (по умолчанию) |
| Быстрая заметка: окошко, текст в накопитель | правый Alt (по умолчанию) |

Obsidian для обеих задач запускать не нужно.

## Установка

1. Создать подкаталог в `e:\Clouds\YandexDisk\Vibecoding\`, например `Obsiclipcapture`, положить туда `Obsiclipcapture.ps1` и `start.vbs`.
2. Запустить `start.vbs`. Через 3 секунды появится иконка в трее — задержка встроена намеренно, чтобы при автозапуске скрипт не опережал готовность системы.
3. При первом запуске само откроется окно настроек клиппера: указать полный путь к хранилищу, папку для клипов, папку вложений. Сохранить.
4. Правый клик по иконке → **Настройки заметок** → проверить папку-накопитель и шаблон имени файла. Сохранить.

Старые `obsidian_clip.cfg` и `Obsicapture.config.json` новая утилита не читает — настройки задаются заново через два окна. Оба прежних скрипта после этого можно убрать из автозапуска.

## Перенос старых настроек

Если прежний клиппер был настроен, проще скопировать значения глазами: строки `vaultpath=`, `inbox=`, `attachments=`, `dateformat=`, `templatercmd=` и `prop_name_*` из `obsidian_clip.cfg` соответствуют полям окна «Настройки клиппера» один к одному. Новый файл называется `obsiclipcapture.cfg` и кладётся рядом со скриптом.

## Автозапуск

`Win+R` → `shell:startup` → Enter. Положить туда ярлык на `start.vbs`.

Прежние ярлыки клипа и капчи из этой папки удалить, иначе три процесса будут бороться за одни и те же хоткеи.

## Работа с заметками

| Действие | Клавиши |
|---|---|
| Открыть окошко | правый Alt, или левый клик по иконке трея, или меню → «Новая заметка» |
| Сохранить и закрыть | `Ctrl+Enter` |
| Закрыть без сохранения | `Escape` |

Текст, закрытый через `Escape`, остаётся черновиком и подставится при следующем вызове — до перезапуска утилиты. Размер и положение окна меняются мышью и запоминаются сразу при закрытии, руками их править не нужно.

## Настройки заметок

| Поле | Что делает |
|---|---|
| Папка-накопитель | Путь внутри хранилища (`Накопитель`) или полный путь с двоеточием (`e:\Clouds\...`) |
| Шаблон имени файла | `{date:ФОРМАТ}` — любой формат даты .NET. Подпапки допустимы: `{date:yyyy}\Неделя {date:ww}.md` |
| Шаблон записи | `{clock}` — эмодзи-часы с шагом полчаса (🕐 🕜 🕑 …), `{text}` — текст заметки |
| Разделитель записей | `\n\n` — пустая строка между записями, `\n` — подряд |
| Свойства заметки | Пишутся только при создании файла. Значения принимают `{date:ФОРМАТ}` |
| Одиночный модификатор | Правый Alt и подобные: они регистрируются опросом клавиатуры, потому что Windows не даёт повесить хоткей на один модификатор |
| Сочетание Ctrl/Alt/Shift + F-клавиша | Работает, когда одиночный модификатор выставлен в «не использовать» |
| Тема | Светлая или тёмная |
| Миганий при появлении | Сколько раз мигнёт заголовок. `0` — совсем без мигания |
| Шрифт, размер | Вид поля ввода |

## Если что-то не работает

**Первым делом — лог.** Рядом со скриптом лежит `obsiclipcapture.log`, туда пишется каждый запуск и каждая ошибка компиляции. Это самый быстрый способ понять, что случилось.

**Иконка не появилась.** Запустить `Obsiclipcapture.ps1` напрямую из PowerShell — текст ошибки будет виден на экране.

**Мелькает или остаётся окно PowerShell.** Заменить `start.vbs` на тот, которым запускался прежний клиппер, и поменять внутри только имя скрипта на `Obsiclipcapture.ps1`. Тот лончер уже проверен на этой машине.

**Один из хоткеев молчит.** Наведи курсор на иконку в трее: подсказка показывает оба текущих сочетания. Если при запуске появлялся баллон о неудачной регистрации — сочетание занято другой программой, поменять в настройках.

**Заметка не появилась.** Проверить папку-накопитель: относительный путь считается от хранилища, так что при пустом пути к хранилищу заметка уйдёт не туда, куда ожидалось.

**Кириллица в меню трея — кракозябры.** `Obsiclipcapture.ps1` пересохранён без BOM. Открыть в Notepad++ → Кодировки → UTF-8 с BOM → сохранить.
